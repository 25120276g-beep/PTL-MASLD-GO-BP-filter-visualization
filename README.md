# GO 富集气泡图（enrichment_bubbleplot）

一套固定格式的 GO 富集气泡图脚本。输入**绘图数据**（手动筛好的 term）和**原始富集结果**，色标自动按原始结果锁定、超过 15 个 term 时按 FDR 自然断点筛选，输出 900 dpi 的 TIFF 图。

## 特点

- **代码与数据分离**：脚本固定，数据只改输入文件；脚本里不写死任何数据。
- **色标锁定全数据集**：颜色范围 = 原始富集结果全部 term 的 `-log10(FDR)` 上下限；即使绘图数据只画少数几个 term，颜色范围仍由全部原始结果锁定，多张图色标一致。
- **自然断点自动筛选**：绘图数据 >15 个 term 时，按 FDR 升序在相邻 `-log10(FDR)` 落差最大处断开，取上方更显著的一簇；≤15 个则全部画出。
- **全自适应**：X 轴刻度、气泡尺寸图例、画布高度全部按数据自动调整。

## 依赖

- R（装好 `ggplot2`、`grid` 即可）
- 字体：Windows 下自动用 Arial；其它系统退回默认 sans（需 Arial 可改脚本顶部 `FONT`）

## 输入格式（两个输入）

**① 绘图数据**（手动筛选后要画的 term；TSV/CSV 均可，脚本自动识别，固定 5 列）：

| 列名 | 用途 |
|---|---|
| `term_id` | GO ID（仅存档，不绘制）|
| `description` | Y 轴描述 |
| `count` | 气泡大小 |
| `strength` | X 轴（富集倍数 = `10^strength`）|
| `fdr` | 颜色（`-log10(FDR)`）|

**② 原始富集结果**（完整富集结果表；TSV/CSV）——**只用来抓色标范围**：

脚本自动识别其中的 FDR 列（`false discovery rate` / `fdr` / `q-value` / `adjusted p` 等），取全部 term 的 `-log10(FDR)` 最小值和最大值作为色标上下限。

## 用法

```bash
Rscript enrichment_bubbleplot.R 绘图数据.csv 原始结果.tsv [输出.tiff]
```

不传输出名时，会在绘图数据同目录生成 `<绘图数据名>_bubbleplot_900dpi.tiff`。

## 关于「自然断点」和「手工筛选」

- 本脚本的流程是：**先手工筛选**（做冗余/语义简化，选出要呈现的核心 term），再画图；色标始终由**原始结果**锁定。
- 自然断点只是辅助：当手工筛完仍 >15 个 term 时，脚本才用自然断点自动精简，便于呈现与美观。
- 自然断点是客观、可复现的显著性聚类，但不含生物学判断。手工筛选的细节参考 `MAFLD_GOBP_筛选标准.md`。
